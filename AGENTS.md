# Repository instructions

Before closing any UI or design task, follow [the mandatory Visual Definition of Done](docs/VISUAL-DEFINITION-OF-DONE.md). The task is **not complete** until the owner can open the approved hosted URL and visually see the exact requested change. Local builds, local servers, test results, source diffs, or screenshots alone do not count as hosted delivery.

Before substantial feature/design work, verify the existing approved publish path. If deployment, an approved URL, or owner access is blocked, mark the task **INCOMPLETE**, stop further feature/design work, and report the exact blocker. Do not create another host or preview, make the app public, broaden access, use fake production data, or claim unverified backend behavior without owner approval. Preserve the prior working version and rollback path.

Follow the repository README and other applicable instructions; this file adds the visual acceptance gate and does not replace them.
