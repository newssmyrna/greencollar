# Commercial Release Acceptance Criteria

Development can be incremental **internally**, but the first paid version must deliver the integrated Autopilot workflow.

- [ ] Secure login and separated business/customer data
- [ ] Business, customer, service, location, photos, preferences and rate setup
- [ ] Recurring schedules, fixed appointments, flexible constraints and job prioritization
- [ ] Operator chooses working hours or job cap, then approves feasible proposed day
- [ ] Real road-based routing and estimated travel/fuel
- [ ] Vehicle and equipment profiles with cost assumptions
- [ ] GPS-assisted arrival/departure and reliable manual start/stop/correction
- [ ] Visible on-site timer, preferences, notes and photos
- [ ] Optional SMS ETA and completion updates with consent and unsubscribe handling
- [ ] Completed jobs produce accurate invoices and secure payment links
- [ ] Customer portal supports payment, future appointment and contract/service requests
- [ ] Historical duration and cost data improve future predictions with visible uncertainty
- [ ] Actual delays cause replan without silently breaking customer commitments
- [ ] Full offline and unreliable-location failure testing
- [ ] Security, data retention/deletion, backups and audit logging
- [ ] End-to-end iOS and Android device testing
- [ ] Usage-based costs validated against proposed subscription pricing

Mockup completion does **not** satisfy these criteria.
